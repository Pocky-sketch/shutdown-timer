# 定时关机 (Shutdown Timer)

粉色 tkinter 界面的 Windows 定时关机工具，带「使用中保护」保险机制。

## 功能

- ⏰ 设定时长后自动关机（`shutdown /s /t`）
- 🛡️ **使用中保护**：检测到键盘/鼠标空闲不足 5 分钟 → 自动顺延 5 分钟再检查，避免干活干一半被关机
- ⏳ **反悔窗口**：判定空闲后留 60 秒取消机会
- 🔒 **故障兜底**：OS 兜底定时比名义时长多 5 分钟，程序崩溃也不会早关
- 🎀 粉色 UI + 自定义图标

## 运行

```bash
python 定时关机源码.py
```

## 保险机制参数（源码顶部可调）

| 常量 | 默认值 | 含义 |
|---|---|---|
| `IDLE_THRESHOLD` | 300s | 距上次输入 ≥5 分钟 = 判定无人使用 |
| `POSTPONE_SECONDS` | 300s | 使用中顺延 5 分钟后再检查 |
| `FINAL_GRACE` | 60s | 判定空闲后的反悔窗口 |
| `FAILSAFE_PAD` | 300s | OS 兜底定时比名义时长多 5 分钟 |
