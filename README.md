# 定时关机 (Shutdown Timer)

粉色 tkinter 界面的 Windows 定时关机小工具，带「使用中保护」保险机制。

## 下载

免安装单文件：[Releases](https://github.com/Pocky-sketch/shutdown-timer/releases/latest) →
`ShutdownTimer-v1.0.0.exe`（Windows 10/11，无需 Python；下载后可改名成 `定时关机.exe`）。

> 附件名用英文是因为 GitHub Release 附件会把非 ASCII 文件名规范化成 `default.exe`。

## 用法

| 方式 | 操作 |
|---|---|
| 日常 | 双击桌面快捷方式 `定时关机.exe`（或直接跑 `定时关机.exe`） |
| 开发 | `pythonw 定时关机源码.py`（同目录需有 `定时关机图标.ico`） |
| 测试 | `python _test_safety.py`（会真的用 1 小时定时做一次布/撤，秒级撤掉） |

## 功能

- ⏰ 设定时长后自动关机（`shutdown /s /t`），预设 15 分 / 30 分 / 1 时 / 2 时 / 3 时
- 🛡️ **使用中保护**：到点先看键鼠是否空闲，空闲才关；正在用电脑则顺延 5 分钟后重新检查
- ⏳ **反悔窗口**：判定空闲后留 60 秒，可点「取消关机」反悔
- 🔒 **故障兜底**：OS 兜底定时比名义时长多 5 分钟，程序崩了/被关了也不会早关
- ♻️ **重开可识别**：关窗后程序退出（省资源），OS 定时仍在跑；再打开会自动认出「上次的关机仍在进行中，还剩多久」，点「取消关机」即可撤销
- 🔁 **单实例**：重复启动不会开出第二个窗口，而是把已有窗口拉到前台
- 🎀 粉色 UI + 自定义图标

## 设计取舍

- **关窗 = 结束程序，不取消定时**。关掉窗口是为了省资源；要撤销请重新打开程序点「取消关机」。
- **使用中保护只看键鼠空闲**。看视频/挂下载时没有输入，会被判定为"没人用"（到点照关）。
- **依赖本地状态文件**判断"重开时是否还有活着的定时"：`%LOCALAPPDATA%\ShutdownTimer\state.json`，
  跨开机自动作废（记录开机时间戳比对）。
- 所有 `shutdown` 调用都带 `CREATE_NO_WINDOW`：无控制台进程调用 `shutdown.exe` 时，
  不加这个标志 Windows 会为它新建终端窗口（实测每次都弹一下 Windows Terminal，且慢约 30 倍）。

## 保险机制参数（源码顶部可调）

| 常量 | 默认值 | 含义 |
|---|---|---|
| `IDLE_THRESHOLD` | 300s | 距上次输入 ≥5 分钟 = 判定无人使用 |
| `POSTPONE_SECONDS` | 300s | 使用中顺延 5 分钟后再检查 |
| `FINAL_GRACE` | 60s | 判定空闲后的反悔窗口 |
| `FAILSAFE_PAD` | 300s | OS 兜底定时比名义时长多 5 分钟 |

## 打包

```bash
python -m PyInstaller --onefile --windowed --name 定时关机 ^
  --icon "定时关机图标.ico" 定时关机源码.py
```
